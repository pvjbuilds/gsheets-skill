gsheets

A Claude skill that creates, reads, and edits Google Sheets in your own Drive — from plain English, with guardrails that stop it mangling your spreadsheet.

You:    "Here's my sheet: <sheet URL>. Set the Q3 row's status to
         Approved, and add a row for the migration project."

Claude: reads the sheet → finds those rows by name → shows you what
        it'll write → writes it in one batch → reads it back

What it does

Create"Build me a reading tracker with tabs for Books, Notes, and Stats"
Read"What's in the Summary tab?"
Write"Set the Q3 row's status to Approved"
Append"Add a row for the migration project"
Format"Make the header bold and show column B as currency"
Highlight"Freeze the header row and turn negative amounts red"
Bulk edit"Apply all 24 changes in this document to the sheet"

Why it doesn't wreck your data

It reads before it writes

Never trusts a row number from a document, a plan, or an earlier conversation. Layouts drift; reading is cheap.

It finds rows by label, not position

And if a label isn't there, it stops and asks rather than guessing a nearby row.

One batch per tab, or nothing

A typo in a tab name aborts the whole write before a single cell changes — so a bad edit can't half-apply.

Spreadsheets only. No Drive.

It authenticates with the spreadsheets scope alone. It cannot list, delete, rename, or share anything in your Google account.

Install

git clone https://github.com/pvjbuilds/gsheets-skill.git
cd gsheets-skill
./install.sh

Once per machine. Works from every project directory afterwards. Full walkthrough, including Google credentials, in SETUP.md.
